# DutchVACC vATIS profile

This repository contains a vATIS profile for all airports in the EHAA sector.
The vATIS client automaticly downloads the profile from this repository.

## ehaa.json

This file needs to be distributed along with the DutchVACC atis package.
It contains an URL that points back to this repository so the full profile
can be downloaded.

## profile.json

This file contains the full vATIS profile and is downloaded
by the vATIS client.
